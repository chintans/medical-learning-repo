# Answer key: Session 3 (2026-11-19)

## Warm-up
- **W1 B** k/c/o = known case of; kidney specialist = nephrologist (nephr- = kidney, -logist = one who studies). Tests the organ-root queue item and the k/c/o shorthand. A = liver, C = heart, D = nerves.
- **W2 C** BD = *bis die*, twice daily; SOS = *si opus sit*, only if needed. A confuses BD with OD and SOS with HS. B confuses BD with TDS. D treats SOS as "stat" (immediately), which is a different instruction.
- **W3 D** cyst- = bladder or sac. Used alone, "cystitis" means the urinary bladder by convention. The gallbladder needs chole- in front (cholecystitis). Tests the chole-/cyst- trap from Session 1.

## Quiz
- **Q1 B** dys- (difficult) + -pnoea (breathing) = breathlessness; "on exertion" = when active. A mixes in -uria. C is apnoea. D is tachypnoea.
- **Q2 C** an- (without) + -uria (urine) = no urine output. "No anuria" means the child IS still passing urine, which is reassuring in a child with diarrhoea and vomiting, because stopping urine is a warning sign of serious dehydration. Tests the "a 'no …' line is a finding" point. A is the reverse (the trap). B = haematuria. D = dysuria.
- **Q3 D** Acute cystitis is the doctor's conclusion (the Dx line). Dysuria = symptom; tachycardia and hepatomegaly = findings (exam and ultrasound).
- **Q4 A** hypo- = below normal → underactive thyroid. s/p = status post. hyster- = uterus, -ectomy = removal. -algia = pain (a symptom), so "complains of joint pain", not "has arthritis". B: hyper vs hypo, and -scopy. C: -otomy, and -itis vs -algia. D: "cancer" is not in the word, and arthr- = joint, not muscle (my-).
- **Q5 C** haemat- (blood) + -uria (urine) = blood in the urine, a property of the urine. Cystitis = bladder inflammation (organ disease); nephropathy = kidney disease; nephrectomy = kidney removal (operation).

## Q6 model answer (grade for the idea)
Plain English: known diabetic (type 2); for a week has been getting breathless when active; on examination is breathing fast and has a fast heart rate; has not coughed up blood; the doctor wants a heart specialist to see him.
Buckets: k/c/o T2DM = background; dyspnoea on exertion = symptom; tachypnoea, tachycardia = findings; "no haemoptysis" = finding (a negative one, ruling out a danger sign); cardiology review = action. **There is no diagnosis yet**, which is the key thing to notice.
Good questions: "What do you think is causing the breathlessness, and what tests will tell us?"; "Why the heart rather than the lungs?"; "Could the diabetes be connected?"
Bonus: haemoptysis = haem- (blood) + -ptysis (spitting) = coughing up blood. Accept "blood from the lungs/coughing blood" as a good guess.
**Full credit:** correct plain English, notices there's no diagnosis (or sorts correctly with no Dx bucket filled), and gives a sensible question. **Half credit:** plain English correct but buckets muddled (e.g. calls tachypnoea a diagnosis), or no question.
