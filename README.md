# Medical learning

My self-study of medicine: ~20 minutes every other day with an AI tutor. Goal: read medical journals confidently, understand what doctors tell me, handle NEET/MBBS-level questions, and build real depth over time. I'm learning this to understand the field. I don't plan to practise.

## How it works
- A scheduled session runs every other morning. The tutor reads this repo (its only memory), writes the day's lesson to `sessions/YYYY-MM-DD.md`, and sends it to me.
- **To answer:** reply in that session with something like `1B 2D 3A 4C 5B`, then my short answer and the minutes I took. Or write them under "Your answers" in the session file and push. The tutor grades them and records them on the next run.
- Doubts can go in the same reply. They're kept in `notes/doubts.md`.

## Map
- `curriculum/roadmap.md` — the full plan and where I am
- `progress/` — log, mastery, spaced-repetition queue
- `glossary.md` — every term learned so far
- `.tutor/` — tutor's answer keys and notes (don't open `keys/` before answering)

*Education only. Not medical advice.*
